## CRUD de Empleados-inicio de sesion

**Descripción del Proyecto:**
Aplicación dieñada para tener un login seguro hacia un modificador de una Base de datos en la cual se puede crear, eliminar, leer y actualizar a los empleados y su información basica.

**Tecnologías Utilizadas:**
- JAVA
- MariaDB / MySQL
- FXML
